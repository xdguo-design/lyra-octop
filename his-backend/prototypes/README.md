# 门诊医嘱原型说明

- 用户任务：医生在一次门诊就诊中查看已签发医嘱、继续编辑草稿或开立新医嘱。
- 结构：同一纵向医嘱列；已签发分区在上、草稿分区在下；成药处方作为分组，一张医嘱允许多个药品明细。
- 展示：列表以药品名开头，按“药品 / 每次用量 / 用法 / 频次 / 疗程 / 领药药房”列示；多药品医嘱的药名和单次用量上下对齐，处方共用信息只展示一次，不加泛化治疗标题。
- 编辑：处方共用信息包括用法、频次、疗程、领药药房、关联诊断、用药时点和处方备注；药品明细分别编辑规格、每次用量、单位及总量。
- 紧凑版：已签发状态只在处方头部显示；草稿处方内任意时刻只展开一条医嘱编辑区，切换编辑对象时收起上一条，避免页面连续铺开多个表单。
- 对照：outpatient-orders-current.html 保留紧凑版调整前页面；order-comparison/sheet.png 并排展示两版医嘱区。
- 核心动作：双击草稿区空行选择医嘱类型；成药在医嘱下方原位编辑；草药、检验、检查、手术、治疗使用独立开立表单。
- 状态约束：已签发内容只读；处方内医嘱状态统一；编辑只允许草稿。
- 设备：桌面医生工作站，最小宽度 900px。
- 验收：类型过滤可搜索；新增/编辑、添加药品、保存草稿、签发状态更新均在浏览器本地演示；特殊类型表单展示各自字段。
- 边界：页面全部为模拟内容，不调用 HIS，不保存或提交真实患者医嘱、申请、处方、费用或执行记录。
