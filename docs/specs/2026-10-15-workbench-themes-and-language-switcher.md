# 工作台主题与语言切换规格

## 目标

- 让设置中的六张主题卡可选择并即时应用到整个 LYRA 工作台；浅色、深色、自动仍独立控制明暗。
- 让语言切换无需展开下拉菜单即可选择，并在保存时及时反馈。
- 在工作台输入框增加模型选择器，行为与聊天页一致。

## 已确认范围

主题包括有风、经典 QQ、和平精英激战秋、同行、涟漪、伙伴。每张卡展示主题名、可辨认的轻量 CSS 预览和当前选中态；点击后全局主题立即更新，并跨刷新保留。场景插画素材目前不在仓库中，因此首版用原创 CSS 配色与背景装饰表达主题，不复制 QQ 或游戏角色/标识。原「敬请期待」卡保留。

主题与明暗模式分开保存、组合生效。主题负责工作台表面色和装饰风格；现有品牌色选择器仍负责品牌强调色，现有偏好及自定义颜色在升级后继续有效。

语言区改为并排显示「简体中文 / English」的按钮组，当前值可见且可用键盘操作。点击即刻切换界面语言并保存到账户偏好；保存失败则恢复原语言并显示错误提示。请求期间防止重复提交。

输入框在 Agent 选择器旁增加模型选择入口，模型候选来自当前 Agent 的已解析模型列表。新对话初始使用账户 `preferred_model`（如无或该模型不属于当前 Agent，则为「自动」）；已有对话优先使用已保存的 `model_ref`，没有时按聊天页现状回退到账户默认模型或「自动」。选择具体模型后仅影响当前对话并保存其 `model_ref`。发送时将选择传给现有聊天 WebSocket 链路；「自动」不传模型覆盖，由 Agent 默认处理。切换 Agent 时重新加载候选；对话模型或账户偏好模型不属于当前 Agent 的候选时，清除失效选择并回退到账户默认模型（若可用），否则回退「自动」。

## 方案比较

1. **全工作台主题预设（采用）**：主题 id 与原有明暗偏好、品牌色分开持久化；通过全局 `data-workbench-theme` 和 CSS 变量切换主题表面与装饰。既实现可切换主题，又不破坏原有主题/品牌色能力。
2. 仅把主题卡映射为品牌色：改动较小，但不能表达截图中的背景主题，且会与现有品牌色选择器重复。
3. 复刻截图插画主题：视觉更接近截图，但没有原始图像素材；直接挪用截图会引入裁切、版权和适配问题，因此不作为首版。

模型选择有“每条消息临时选择”与“按对话保存”两种。采用按对话保存的现有聊天页行为，并用账户默认模型初始化新对话，避免新增另一套全局偏好。聊天接口以 nullable `model_ref` 表示覆盖；「自动」清除覆盖值，之后重新进入时会按默认优先级恢复账户默认模型（若当前 Agent 可用），否则显示「自动」。

## 交互与存储

- 主题卡使用按钮语义、`aria-pressed` 和明确焦点态；选择后立即更新根元素标记及 localStorage 中现有 `theme` 对象的可选主题字段。
- 读取旧版 `theme` 字符串、旧 palette key 或不认识的主题 id 时保留现有迁移行为，并将主题回退至默认主题；不清除有效的明暗模式、品牌色或自定义颜色。
- 当前模式 `preference` (`system/light/dark`) 和 `palette/customColor` 继续独立工作。主题选择不得把 `system` 改成固定明暗模式。
- 语言按钮先在本地应用所选语言，再提交现有 `/preferences` 更新；失败时回滚至操作前语言并通知用户。保存中锁定两个按钮，避免快速连点造成乱序回写。
- 模型候选随当前 Agent 加载；“自动”始终可选。选择具体模型时更新本地选中态和 `model_ref`，发送当前消息时显式带入当前模型引用；“自动”清除模型覆盖并在新对话首条消息中不发送覆盖字段。

## 失败场景与保护

- localStorage 中主题字段被截断或伪造：校验白名单并采用默认主题，继续加载其余合法外观偏好。
- 保存语言请求超时/失败：恢复原语言并提供可见反馈，不让 UI 与账户偏好静默分叉。
- 连续切换语言造成响应乱序：请求期间禁用按钮，保证最后一次已提交状态一致。
- 当前 Agent 的模型列表请求失败或为空：模型入口仍显示“自动”，按 Agent 默认值发送，不阻断聊天。
- Agent 切换后账户默认模型不属于新 Agent 的候选：清理该模型选择并回退到“自动”，避免发送无效引用。
- 账户默认模型被删除或关闭：从当前 Agent 候选校验默认值；不可用时显示“自动”，不阻断发送。
- 对话已保存模型后来被删除、禁用或不再属于当前 Agent：不发送失效引用，回退到账户默认模型（若可用），否则使用“自动”。
- 深色模式下预览或主题装饰对比不足：主题变量按明暗两套定义，装饰不承载文字信息，主题卡保持可读边框和焦点态。

## 验收

- 六张主题卡均可鼠标、键盘选择；选中效果即时、刷新后保留；「敬请期待」仍不可选。
- 六主题与浅色、深色、自动任意组合时可正常显示；旧存储格式和未知主题值不阻止页面启动。
- 中英文按钮始终可见；点击立即更新 UI；保存失败显示错误并还原；按钮可通过键盘聚焦和激活。
- 输入框可选择当前 Agent 可用模型或“自动”；具体模型可按对话保存；新对话按账户默认值初始化；模型列表失败时仍可按 Agent 默认模型发送。
- 主题覆盖 LYRA 工作台 shell 和使用共享主题变量的内置页面；第三方 iframe 内容不纳入。修改范围限于工作台输入框、设置 UI、主题上下文/存储、共享主题变量和中英文案；复用现有 API，不改服务端偏好 schema。

- 前端 TypeScript 检查和生产构建。
- 对外观存储兼容、主题组合、语言保存失败回滚、模型按 Agent / 对话切换验证；在桌面与窄屏检查输入框和设置对话框的排版及焦点态。
