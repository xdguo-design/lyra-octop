# 住院登记 Demo 音量响应波形设计

## 目标

在语音输入时显示麦克风是否实际收到声音，并明确提示点击开始、说完后再次点击停止。这样“识别为空”时可以区分无明显输入音量和识别服务未产出文字。

## 实现

- `useVoiceInput` 增加可选的本地音量回调，不改变 STT 请求、录音内容或其他调用方行为。
- 豆包等录音后上传的路径复用已授权的 `MediaStream`，用 `AudioContext` 分析短时 RMS 音量；实时识别路径从已有 PCM 输入帧计算 RMS。
- 入院 Demo 只在录音期间更新波形；停止、失败或卸载时释放分析器并把波形归零。音量只用于本地显示，不保存。
- UI 显示开始/停止和识别中状态，用户可看到录音是否启动、是否收到明显声音。

## 失败处理与验证

- 音量分析初始化失败时，录音与识别照常工作，波形保持静止。
- 确保静音输入仍显示低音量、停止录音后归零，短促音量变化能反映到波形。
- 完成后运行 Dashboard TypeScript 检查及生产构建；不以模拟构建替代真实设备试音。

## 已确认

用户选择“音量响应波形”。真实麦克风试音需用户自行操作，且当前激活的豆包服务会接收录音。
