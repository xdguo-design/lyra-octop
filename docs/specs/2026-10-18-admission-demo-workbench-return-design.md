# 住院登记 Demo 返回工作台入口设计

## 目标

让用户从独立打开的住院登记 Demo 返回 Octop 工作台，入口外观与星球乐园相同。

## 方案

在 Demo 页面最上方加入与星球乐园一致的工作台标题栏：左侧“返回工作台”按钮和应用名称，右侧提供新窗口打开、全屏和关闭操作。返回与关闭都导航到 `/home`。底部现有“返回首页”仍保留，医院蓝色导航栏及 1536×1024 kiosk 画布样式保持不变；新增标题栏占用自己的 57px 高度，kiosk 画布按剩余可视区缩放。

## 备选与取舍

1. 只在医院蓝色导航栏增加返回按钮：改动最少，但不符合用户要求的星球乐园样式。
2. 使用独立工作台标题栏：复用星球乐园的视觉和熟悉操作，推荐采用。

## 验收

- `/admission-demo` 顶部可见“返回工作台”，点击后到 `/home`。
- 关闭按钮返回 `/home`；新窗口打开指向 `/admission-demo`；全屏作用于 Demo 容器。
- 底部“返回首页”功能保留，kiosk 画布在标题栏下可见且不被覆盖。
