# 首页工作台主题覆盖设计

## 目标与约束

让选中的视觉主题覆盖首页工作台完整 UI：侧栏、顶栏、内容区、对话输入区、项目与任务、平台面板、设置弹窗及其菜单。继续使用现有 `data-skin`、明暗模式 `data-theme`、品牌色 `data-palette` 和 `--fn-*` token；保留主题背景图与主题各自的装饰风格。不改业务逻辑或主题选择流程。

## 方案

1. 只覆盖侧栏：改动最小，但输入框、悬浮菜单等仍可能沿用旧色值。
2. 在工作台样式尾部补全主题 token 映射（选用）：扩展现有覆盖规则到尚未接入主题的 UI 表面与控件，不替换主题系统，也不重构旧样式。对挂载在 body 下的工作台弹层增加工作台专属 popup class 后再使用主题样式，避免污染其他页面。

## 验收与失败场景

- 浅色和深色主题、不同品牌色与视觉皮肤组合下，工作台可见表面、文字、边框、输入控件与弹层均使用对应主题色；背景图仍可见。
- 窄屏下侧栏转为顶部导航，主题背景和控件对比度保持可读。
- 没有 `data-skin` 时保持当前默认样式；所用 `--fn-*` token 由现有 `theme-vars.css` 保证。
- 改动限于 `dashboard/src/pages/Home/home-workbench.css` 与为 body portal 指定 scoped class 所需的 `dashboard/src/pages/Home/index.tsx`，验证前端 TypeScript/build 相关流程按仓库要求执行。
