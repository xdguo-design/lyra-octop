# 入院登记聊天对话框样式统一设计

## 目标

让首页与表单页的聊天对话框采用同一外观，以用户提供的手机截图作为视觉基准。只统一聊天对话框，不涉及退出确认、数字键盘等其他弹窗。

## 现状与约束

- `ConversationDialog.vue` 已由首页和表单页共用。
- 首页通过全屏遮罩显示；窄屏下采用底部面板和紧凑输入栏。
- 表单页当前显示为悬浮面板，并提供字段快捷选项；统一后也使用同一遮罩弹窗。
- 首页与表单页的标题、消息、输入、语音和字段选择行为不同，需保留。
- 用户截图展示手机端聊天面板；统一后两个页面均采用相同的弹窗定位、边框、圆角、阴影、消息区域和底部输入栏样式。

## 方案比较

1. **统一聊天弹窗外壳，保留页面专属内容（推荐）**：两页使用同一种遮罩与弹窗布局；标题/说明、字段选项及首页移动输入模式仍按上下文显示。改动集中在共享组件样式和挂载容器，行为回归面较小。
2. **把首页和表单页整个内容区都做成完全相同**：可让布局更一致，但会隐藏或挤压表单页字段选项与流程信息，并改变现有交互层级。

选择方案 1：统一用户看到的弹窗外观，同时不改变字段补充流程。

## 设计细节

- 移除首页/表单页因 `home` 状态导致的弹窗定位与布局差异；两页共用遮罩、弹窗尺寸约束、圆角、阴影、头部、消息区和底部栏。
- 桌面端使用居中对话框；窄屏使用贴近视口底部的聊天面板，保留安全区和滚动行为。
- 两页均使用关闭按钮、点击遮罩关闭；弹窗打开期间底层表单不可交互。首页原有遮罩关闭行为保持，表单页由浮动面板改为模态弹窗。
- 文本/语音输入及字段选项沿用现有上下文规则，不改消息发送、AI 逻辑、持久化或页面跳转。
- 仅适用于 `demos/admission-registration/frontend` 的 Vue Demo。平台 `dashboard/src/pages/AdmissionDemo` 的旧 React 弹窗不在本次范围。

## 验收与验证

- 首页与表单页在相同桌面/手机视口下打开聊天时，遮罩、面板位置、尺寸、边框、圆角、阴影、头部/消息/输入区域样式一致；页面文案和字段选项可不同。
- 手机宽度下两页都使用同款底部面板，不溢出视口；软键盘弹出时输入栏仍可见，消息区可滚动。
- 两页点击关闭按钮或遮罩均可收起对话框；对话框打开时底层表单不可操作。
- 表单页字段选项仍可选择；首页文字/语音入口与现有流程保持可用。
- 运行入院 Demo 前端测试及生产构建，并查看 `git diff --check`。
