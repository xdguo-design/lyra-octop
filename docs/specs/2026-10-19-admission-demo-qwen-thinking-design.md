# 入院登记提取关闭 Qwen3.5 思考模式

**状态：** 用户已确认，进入实施  
**日期：** 2026-10-19

## 目标与约束

入院登记字段提取使用 ModelScope 提供的 Qwen3.5-27B 时，关闭默认思考模式以降低等待时间。只影响 `/api/admission-demo/extract` 使用的该模型请求，不修改平台当前激活模型、其他对话或全局模型配置，也不增加 UI 开关。

## 方案

- **A（采用）：** 当激活模型提供方为 ModelScope 且模型 ID 为 `Qwen/Qwen3.5-27B` 时，在该次提取请求附带 `chat_template_kwargs.enable_thinking=false`。其他提供方和模型保持原调用行为。
- **B：** 在管理界面增加思考模式开关并持久化设置。该方案触及模型配置与 UI，范围超出登记提取的即时需求。

采用 A：已实测同一条字段提取请求在默认思考模式约 14.1 秒，临时关闭思考约 4.8 秒；该方式不改全局配置。

## 调用与验证

从活动模型工厂取得模型后，仅对匹配的 ModelScope `Qwen/Qwen3.5-27B` 请求绑定 `extra_body={"chat_template_kwargs":{"enable_thinking":false}}`，然后复用现有提取、字段白名单和 API 错误处理。测试验证匹配时仅绑定一次指定参数；其他 ModelScope 模型和其他提供方不绑定；字段提取输入输出合同不变。手工验证使用合成登记语句，检查耗时和候选字段，不使用真实患者数据。

## 风险与限制

单次延迟会随服务负载变化。思考模式关闭后仍需通过现有字段规则与用户确认保障登记信息准确；本改动不保证其他提供方忽略或支持该参数，因为该参数只发送给 ModelScope Qwen3.5-27B。
