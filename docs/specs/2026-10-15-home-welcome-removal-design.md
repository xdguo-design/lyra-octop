# 首页欢迎区移除设计

## 目标与范围

移除首页空会话状态中的欢迎区全部内容：品牌标题、两个入口卡片、示例任务、平台能力卡片和团队提示。保留下方对话输入框，并保持其位于页面底部；已有对话视图、导航和输入功能不变。

## 实现选择

推荐删除 `dashboard/src/pages/Home/index.tsx` 中的 `wb-welcome` 区块及其专用的 `PROMPTS`、`CAPABILITIES` 常量和未使用引用。相比仅用 CSS 隐藏，直接删除 JSX 不会留下不可见的交互结构。同步调整空状态父级布局，使输入框仍贴近页面底部。

## 验收与风险

- 首页没有欢迎标题、入口、示例任务、能力卡片和团队提示。
- 对话输入框仍显示在工作区底部；发送消息及已有聊天视图不受影响。
- 更新首页测试，使其验证这些内容不存在、输入框仍可用。
- 检查桌面及窄屏布局；主要风险是删除占位区域后 flex 布局改变输入框位置。
