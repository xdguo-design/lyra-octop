# 聊天自动选择连接器设计

## 核心目标

普通聊天中，用户只描述任务即可；Agent 根据意图选择合适的已连接工具。用户不必查看或手动挑选 Agent Mail 或其他连接器；连接器启用和授权由连接器管理页处理。

## 当前行为

聊天输入框中的连接器 chips 对应 `selectedConnectors`；`useChatSend` 将该列表随本轮消息发送。服务端只为本轮选中的连接器准备工具，因此 Agent 无法自行选择一个未被选中的连接器。Ask/Plan 模式目前不会传连接器。

## 设计选择

1. **纯自动模式（采用）**：普通 Craft 聊天将当前用户可见、已启用、状态 active 且具备凭据的连接器工具提供给 Agent。Agent 按用户请求选择是否调用及调用哪一个。聊天 composer 不显示连接器清单、chips、picker 或连接器名称建议，也不提供手动限制。
2. **意图分类后按需加载**：先分类消息意图，再只加载预测相关的连接器。工具上下文更小，但需要新增分类与路由行为，并可能因分类错误漏掉所需工具；当前不采用。
3. **维持手动选择**：不改变现有机制；这不满足用户希望 Agent 自主判断工具的目标。

## 范围与规则

- 自动模式仅作用于 Dashboard 的普通 Craft 聊天。
- 可用范围限于当前用户可见且 active、已配置凭据的连接器实例，以及该用户已启用的自定义 MCP 服务；绝不把其他用户的私有连接器加入工具集。
- Ask/Plan 模式仍将连接器工具集置空，后端也必须按模式强制阻止外部连接器，不能依赖前端隐藏选择器。
- 聊天 composer 不显示连接器 chips、选择器或连接器名称建议；连接器管理页继续负责启用和授权配置。
- 忽略并停止写入旧的 per-agent 连接器选择持久化值，防止旧列表静默限制自动模式；不迁移旧值。
- Cron、IM、`default_open` 和连接器管理页行为不变。
- 现有 HITL 审批、权限检查、凭据隔离及连接器工具自身确认流程不变；自动模式只决定工具可见性，不自动批准有副作用的调用。

## 交互与数据流

1. composer 不展示连接器名称、chips、选择控件或连接器名称建议；启用和授权仍在连接器管理页完成。
2. 发送普通 Craft 消息时显式传递 `auto` 选择模式；服务端解析当前用户的可用连接器集合，并复用已有的连接器加载/注册路径。
3. Ask/Plan 将有效连接器列表强制设为空，无论请求负载如何。
4. 工具 readiness 使用自动解析后的有效范围，状态不得把未授权连接器报告为可用。

## 方案落点

- Dashboard chat composer：移除 connector chips、connector picker 及聊天输入内的 connector 名称建议，不再维护每轮 connector selection。
- Dashboard send/websocket payload：增加显式的 `auto` 模式字段，避免空列表与自动解析语义混淆；不再发送 Dashboard 侧 connector 名单。
- Backend dashboard turn preparation：仅对 Craft 的 `auto` 展开当前用户有权使用的连接器名称；对 Ask/Plan 强制空集合。
- Agent registry/readiness：为自动展开后的集合准备工具并报告真实有效状态；复用当前注册路径，不增设意图分类器。未带新字段的旧客户端按既有兼容行为处理。

## 验收与测试设计

- 新会话默认自动模式，用户无需点 Agent Mail chip 即可在发邮件意图下获得可用 Agent Mail 工具。
- Agent Mail 未启用、无凭据、非 active 时不进入自动工具集；其他已授权连接器仍可正常提供。
- composer 不展示连接器清单、chips、picker 或连接器名称建议；发信等任务无需用户选择连接器。
- 私有连接器不会跨用户自动暴露；共享连接器只在现有可见性规则允许时进入集合。
- Ask/Plan 不加载外部连接器，即使请求手动传入名称或 auto 模式。
- `default_open`、Cron、IM 的已有默认选择行为不改变。
- 自动提供工具不会绕过 HITL；邮件发送仍需先预览，之后显式批准并确认。

## 风险与限制

- 自动模式会扩大每轮对话可见的工具数和上下文长度；当前选择比新增意图分类器更简单可控。后续若工具量成为实际问题，再基于测量引入按需路由。
- 工具可见性不等同于服务可用性；连接器授权可能过期或上游故障，调用错误应由现有工具错误路径呈现。
- 旧的 per-agent 保存列表不能继续静默限制自动聊天；启用或授权失效时对应连接器不会进入工具集。
