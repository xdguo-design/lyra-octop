# 工作台项目、代码浏览与 Agent 身份设计

## 目标

把工作台项目升级为账号级数据：项目可设置图标、含文件夹和任务对话；可在项目内新建任务，并从输入框选择项目。为“星球”项目提供只读代码浏览。主 Agent 可改名和上传头像，Agent 选择器与协作成员展示头像；ACP runner 作为主 Agent 可调用的协作能力展示，不进入聊天对象选择器。

## 已确认约束

- 项目、文件夹及会话归属按账号保存并跨设备同步。
- 文件夹用于归类任务会话。删除文件夹后，会话回到所属项目根目录；删除项目后，会话变为未分组；都不删除会话本体。
- 从项目创建的新任务归入该项目；输入框“+”可给新建或现有会话选择项目/文件夹。
- ACP 只展示为主 Agent 的协作成员，不可直接作为聊天对象。
- 星球代码采用网页只读浏览。根据本机仓库发现，候选代码根目录为 `D:\WorkSpace\lyra-planet`；服务端通过显式配置绑定根目录，不接受用户提交任意文件系统路径。
- 主 Agent 复用团队 Agent 的名称与头像字段；Agent 选择器展示头像，ACP runner 展示名称与工具图标。

## 方案

账号级项目数据存于服务端数据库，API 按当前用户隔离。沿用当前未发布的迁移 `022`，不另起迁移号。增加项目、文件夹和线程归属持久化；线程本身仍由现有 API 管理。

代码浏览采用固定根目录配置和只读 API。API 规范化路径并拒绝路径越界、符号链接越界、隐藏目录、凭证文件、运行数据目录和超出大小限制的文件。浏览器只显示目录与文本文件，不提供上传、编辑或执行。

工作台复用现有项目和聊天交互；项目列表改为服务端数据，任务行按当前筛选显示。使用已有图标/头像控件与 Agent 字段，不引入新的 UI 依赖。

## 权限与失败场景

1. 用户伪造其他账号的项目/文件夹/线程 ID：所有读写由 owner 条件约束，归属失败返回未找到。
2. 用户借助 `..` 或符号链接读取代码根目录外文件：服务端对解析后的目标再次检查根路径，拒绝越界目标。
3. 大文件或二进制文件拖慢服务：目录列表只枚举直接子项，单文件读取设字节上限并只允许文本类型。
4. 删除项目/文件夹造成对话丢失：事务只清除归属，不调用会话删除 API。
5. ACP 配置读取失败：聊天对象选择器仍只显示已有 Agent，ACP 展示区域显示空状态或隐藏，不阻断发消息。

## 不包含

- 不在网页中编辑或运行项目代码。
- 不允许用户从网页绑定任意服务器目录。
- 不为 ACP runner 增加头像上传字段；使用 runner 名称和工具图标。
- 不生成新的吉祥物图片；先让用户为 Agent 上传实际头像。
