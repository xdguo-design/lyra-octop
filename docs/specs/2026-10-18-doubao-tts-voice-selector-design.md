# 豆包 TTS 音色选择器设计

## 目标

在 Octop 的豆包语音配置弹窗中提供可选的豆包 TTS 2.0 中文音色，解决当前只能手动输入 `voice_id` 的问题。

## 方案

- 将音色 ID 文本框改为可搜索选择控件，提供一组火山引擎官方列出的中文 TTS 2.0 公版音色。
- 保留当前服务端的文静毛毛系统默认音色，选项文案显示音色名，提交值仍是对应 `voice_id`。
- 内置选项：文静毛毛（现有默认）、温柔妈妈、温柔淑女、清澈梓梓、温柔小哥、解说小明；后五项取自[火山引擎音色列表](https://docs.volcengine.com/docs/DoubaoVoice/Tonelist-1?lang=zh)。
- 保留“自定义音色 ID”选项，兼容其他或已有自定义音色。
- 已保存的非列表音色作为自定义值显示，不丢弃现有 `extra.voice_id`。
- 不请求云端音色列表、不新增 API/数据库字段；沿用现有 `voice_id` 持久化和 TTS 2.0 请求。

## 验收

- 可从下拉列表选择常用中文音色并保存。
- 可按音色名称搜索下拉列表。
- 可输入自定义音色 ID 并保存。
- 编辑已有配置时保留选中的或自定义音色。
- STT、API Key 和服务端语音请求行为不变。

## 风险与限制

- 火山引擎可用音色可能随账号、服务版本或控制台变更；列表只放官方文档列出的通用 TTS 2.0 音色，并保留自定义入口。
- 下拉选择不试听音色；云端 TTS 探测可能产生用量，试听不纳入本次改动。
