# 模型提供商筛选设计

## 目标

在“模型配置”的“预置提供商”区域增加名称搜索，方便从较多的云端或本地服务商中定位配置项。

## 方案

- 在“预置提供商”标题旁放置一个轻量搜索框，复用已有 Ant Design 控件，不增加依赖。
- 搜索只作用于当前“云端 / 本地”页签，不改变自定义提供商列表、活动模型池或任何配置。
- 对单项预置匹配名称和站点/变体名称；对分组卡片，匹配品牌名时保留整个组，否则仅保留名称匹配的站点/变体。
- 云端搜索覆盖折叠的“更多模型提供商”；有搜索词时展示匹配结果，清空后恢复现有默认折叠状态。
- 忽略首尾空白并按大小写不敏感的子串匹配。无匹配时显示本地化空状态。
- 空状态文案同时添加到 `dashboard/src/locales/zh.json` 与 `dashboard/src/locales/en.json`，保持语言键一致。
- 搜索状态仅保存在当前页面内存中；不调用 API、不写配置或浏览器存储。

## 验收与验证

- 输入品牌名可定位提供商；输入站点/变体名可定位对应配置项。
- 云端搜索可找到默认折叠区域里的提供商；清空后默认展示与折叠行为不变。
- 本地页签搜索只影响本地预置项；自定义提供商和活动模型池不受影响。
- 用 `uv run pytest tests/unit/i18n -q` 检查语言键一致性，并用 `cd dashboard && npx tsc -b` 与 `npm run build` 验证前端。

## 失败场景

- 空白或不匹配查询应有清楚空状态，清空后可恢复全部条目。
- 对分组内站点筛选时只改变展示集合，不修改已有服务商配置。
- 快速输入或清除查询不会触发网络请求，也不会重置配置。
