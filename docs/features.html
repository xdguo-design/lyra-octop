一个由你掌控的 AI 工作台

Lyra Octop 将多模型对话、Agent、知识、自动化和团队协作放在可自托管的平台中。你可以从浏览器、命令行或已连接的消息通道使用它。

平台与数据

自托管、多用户

在自己的机器或容器运行服务；支持 SQLite 与 PostgreSQL、多用户账号、角色权限、审计记录、备份和系统设置。

模型

连接你选择的模型

管理云端与本地模型供应商、模型参数和连接测试。模型是否可用取决于供应商配置、凭据、网络和模型能力。

对话

围绕工作持续对话

按 Agent 管理聊天和历史；上传文件、查看附件、恢复历史记录，并使用联网搜索等已配置的工具。

Agent

配置不同的工作助手

创建专家 Agent，配置人格、指令、知识库、Skills 与连接器；通过权限和审批规则控制工具的使用范围。

知识与扩展

让知识和工具可组合

管理知识库、插件、MCP Connector 和可选扩展；能力受实际安装的组件与所连服务支持范围影响。

协作

团队、ACP 与工具审批

使用 Agent Teams、Human-in-the-Loop 审批和 ACP 接入 IDE 等客户端；协作动作依照 Agent 与用户权限执行。

消息通道

从常用入口触达助手

配置飞书、钉钉、企业微信、Telegram、Discord 等支持的通道，让助手在 Web 对话之外接收消息。

自动化

Cron 定时运行与记录

管理定时任务、手动触发运行、查看持久化运行记录，并在当前服务进程中取消正在运行的任务。

工作台与创作

项目、内容与演示能力

使用工作台项目、资源与创作页面；可按部署配置体验语音、图片/视频生成及 Admission 演示功能。

远程操作

浏览器和桌面自动化

按需启用浏览器自动化与远程桌面能力。它们依赖相应运行时、权限和服务配置，不会因安装主程序而自动启用。

管理

Web 控制台与 CLI

用 Web 控制台管理账号、模型、Agent、通道、定时任务和系统；用 CLI 启动服务并完成常见维护操作。

部署

从本机到容器

支持安装脚本、Python 环境和 Docker 部署；可配置 TLS、系统服务、运行数据目录与数据库。

能力状态：以上介绍的是产品现有模块，不代表每个第三方 Provider、文件格式和端到端场景均已完成验收。文件 OCR/引用/编辑/导出闭环、音频转写与视频抽帧理解、跨进程 Cron 取消及 Projects/routines 仍有路线图工作。请查看测试文档中的“未完成与外部依赖”部分。
