# Lyra Octop 线下测试指南

本指南用于本机或隔离测试环境验证当前代码。自动化通过不替代 Provider、浏览器、PostgreSQL 或多实例的人工验收。测试时使用合成数据与测试账号，不要导入真实用户文件或生产密钥。

## 1. 环境准备

- Python 3.12+，按仓库 lockfile 安装依赖；Node/npm 与 `dashboard/package-lock.json` 匹配。
- 仓库根目录运行后端命令；前端命令在 `dashboard/` 执行。
- 使用临时 `OCTOP_HOME` 和单独测试数据库。集成测试使用仓库测试夹具，不连接生产库。
- 手工权限测试至少准备管理员、普通用户 A、普通用户 B 和两个私有 Agent。
- 只有需要真实 Provider 联调时才写测试 Key；没有测试 Key 时将相关项目记为“未测”，不要用 mock 结果代替。

## 2. 自动化质量门禁

在仓库根目录运行：

```bash
make all
```

该命令执行仓库格式、lint、类型检查和测试门禁。若它在环境依赖、外部遥测或系统包处失败，保留完整输出并记录为“环境阻塞/未完成”，不可报告为通过。

针对本次重点可单独运行：

```bash
PYTHONPATH=src uv run --no-sync pytest \
  tests/unit/db/test_db_pool.py \
  tests/unit/db/test_repo_cron.py \
  tests/unit/cron/test_cron_job.py \
  tests/unit/cron/test_cron_manager.py \
  tests/integration/test_cron_api.py \
  tests/integration/test_cron_shared_agent.py \
  tests/unit/cron/test_cron_tools.py \
  tests/unit/cli/test_cron_run_now.py -q
```

## 3. 手工验收步骤

| 编号 | 操作                                                           | 预期                                                                       | 结果 |
| ---- | -------------------------------------------------------------- | -------------------------------------------------------------------------- | ---- |
| A1   | 登录后创建多个会话，进入历史分页；分页请求未返回时刷新当前会话 | 刷新结果不被旧响应覆盖，消息无重复或错序                                   |      |
| A2   | 历史分页加载中切换到另一个会话，待旧请求返回                   | 旧会话消息不串入当前会话                                                   |      |
| B1   | 普通用户创建工作台项目并尝试开启代码浏览                       | 服务端拒绝普通用户越权，默认权限为关闭                                     |      |
| B2   | 管理员授权代码浏览后读取授权根内文件，再请求根外和路径穿越路径 | 仅授权根内可读；越界请求不泄漏内容                                         |      |
| C1   | 上传附件后移除未发送草稿，再上传并发送附件                     | 未发送草稿可删除；已发送附件仍可在历史查看                                 |      |
| C2   | A 用户访问 B 用户草稿或删除已绑定文件                          | 请求被拒绝，不泄漏内容，不改变文件                                         |      |
| D1   | 使用真实搜索 Provider 搜索并打开历史会话                       | 来源 URL 来自工具结果、去重且刷新后恢复                                    |      |
| E1   | 创建 Cron 后执行 Run now，打开详情抽屉                         | API 返回 `202` 与 `run_id`；抽屉显示运行记录和终态                         |      |
| E2   | 启动一个可控长任务，在抽屉取消                                 | 本进程内运行记录变为 cancelled；外部已发生的副作用不回滚                   |      |
| E3   | 启动测试服务并让任务处于 running 后重启，再查看历史            | 过期实例任务显示 interrupted，不自动重放                                   |      |
| E4   | 建立一次性 `date:` Cron，等待触发后重启服务                    | 任务不会被再次调度                                                         |      |
| F1   | 上传 TXT/CSV/可搜索 PDF/DOCX/XLSX/PPTX 和扫描 PDF              | 已支持内容显示实际读取结果；未支持/OCR 缺失/超范围必须显示部分或未支持状态 |      |
| F2   | 上传音频与视频，查看消息/历史/附件                             | 上传和受保护预览可测；当前不把路径提示当作已转写/理解                      |      |
| G1   | 在 HTTPS 页面允许麦克风并配置有效 STT/TTS Provider 后录音/试听 | Provider 已配置时走真实端到端；无凭据明确标记未测                          |      |
| H1   | 打开侧栏“更多”，分别进入“功能介绍”和“更新日志”                 | 两项均可从控制台菜单进入；页面内容、返回导航与当前语言显示正常             |      |

既有 A–D 详细步骤（分页竞态、代码权限、草稿生命周期、搜索来源）也可参照 [P0/OCT 汇总验收单](p0-oct-005-summary-acceptance.md)。
