## 2. A 组：聊天历史分页与刷新竞态（OCT-001）

| 编号 | 操作 | 预期结果 | 结果/备注 |
|---|---|---|---|
| A1 | 打开多页历史会话，连续触发“加载更早消息” | 消息按时间顺序排列，不重复；分页游标持续前进 | |
| A2 | 加载更早消息尚未返回时刷新当前会话 | 旧分页响应不覆盖刷新结果；刷新后消息顺序和游标正确 | |
| A3 | 加载期间切换到另一会话，等待请求返回 | 旧会话响应不串入新会话；新会话内容不被替换 | |
| A4 | 切回原会话继续翻页 | 可继续加载；无重复、倒序或错误显示“没有更多消息” | |

**失败判定：** 旧响应覆盖新状态、会话间串消息、重复消息、游标回退或错误终止分页，任一出现即不通过。

## 3. B 组：工作台代码浏览权限（OCT-002）

| 编号 | 操作 | 预期结果 | 结果/备注 |
|---|---|---|---|
| B1 | 管理员新建项目，不开启代码浏览 | `code_enabled=false`；代码目录入口不可用 | |
| B2 | 管理员显式开启代码浏览并访问配置根目录内普通文件 | 允许读取授权目录内文件 | |
| B3 | 普通用户创建名称为“星球”的项目 | 不因项目名称自动开启代码浏览 | |
| B4 | 普通用户创建或更新项目并提交 `code_enabled=true` | 服务端拒绝（预期 403）；权限状态不改变 | |
| B5 | 普通用户请求旧项目代码目录或文件接口 | 拒绝访问（预期 404）；不返回目录或文件内容 | |
| B6 | 管理员导入旧浏览器项目 | 项目导入成功，代码浏览默认关闭 | |
| B7 | 请求配置根目录以外路径、路径穿越路径 | 拒绝读取，不泄露文件内容 | |

创建项目示例：`{"name":"测试项目","icon":"📁","code_enabled":true}`。如 UI 没有开关，可用 API 客户端分别以管理员和普通用户 Token 验证。测试根目录来自测试实例配置，不在项目请求中传入本地路径。

## 4. C 组：聊天附件草稿生命周期（OCT-003）

| 编号 | 操作 | 预期结果 | 结果/备注 |
|---|---|---|---|
| C1 | 上传完成后、发送消息前显式移除附件 | 本人未绑定会话的草稿被软删除；输入区不再显示附件 | |
| C2 | 上传完成后清空输入内容/附件区，但不发送 | 不因清空动作误删已完成上传的草稿 | |
| C3 | 上传完成后切换 Agent | 不误删已完成上传的草稿 | |
| C4 | 上传仍在进行时切换 Agent，等待旧请求返回 | 旧 Agent 的迟到上传结果被清理，不留下孤儿草稿 | |
| C5 | 发送带附件消息，完成后重开会话并打开附件 | 已绑定会话的附件仍可读取，不被草稿清理删除 | |
| C6 | 用户 A 删除用户 B 的文件草稿 | 返回 404；如果用户在 Agent 级权限检查处先被拦截，也可返回 403；不得删除文件或泄露内容 | |
| C7 | 对已绑定会话的文件调用草稿删除接口 | 返回 404，不删除已绑定文件 | |

辅助接口：`DELETE /api/agents/{agent_id}/files/{file_id}/draft`。本人未绑定会话的草稿预期返回 204；已绑定、他人或不存在文件预期返回 404。可在 Network 面板查看状态码，不要复制或分享附件正文。

## 5. D 组：联网搜索来源与历史恢复（OCT-005）

| 编号 | 操作 | 预期结果 | 结果/备注 |
|---|---|---|---|
| D1 | 用真实搜索工具发起一次搜索 | 对应助手轮次显示来源标题和 Provider；来源与原始工具结果一致 | |
| D2 | 搜索多次，包含重复 URL | 同一 URL 只显示一次；不同来源保留正确标题 | |
| D3 | 查看无结果、普通工具输出、非法 URL 或未知格式的回答 | 不出现空来源卡片，不从模型正文猜造链接 | |
| D4 | 分别验证已配置的 Tavily、Google、Brave、Kimi Provider | 能识别各自返回的有效来源；无效或缺少 URL 的结果不展示为链接 | |
| D5 | 点击来源链接 | 打开正确的 HTTP(S) 目标，不发生错误域名导航 | |
| D6 | 刷新页面并重新打开该历史会话 | 来源仍从持久化工具消息恢复，归属正确助手轮次 | |

若没有 Provider Key，D1、D4 只能用已有工具记录或模拟数据核对前端，不代表真实上游验收；请将真实联网调用标为“未测”。

**来源验收原则：** 每条来源都能追溯到工具原始结果；仅接受 HTTP(S) URL；标题不能为空；不根据助手回答补造来源。

## 6. E 组：文件、语音、媒体与 Cron 闭环（OCT-004）

| 编号 | 操作 | 预期结果 | 结果/备注 |
|---|---|---|---|
| E1 | 上传 TXT、CSV、可搜索 PDF、DOCX、XLSX、PPTX，分别让助手读取 | 支持格式显示真实解析状态和来源位置；超预算、扫描页或不支持格式明确显示 partial/needs_ocr/unsupported，不得声称完整阅读 | |
| E2 | 上传并读取附件后，通过 workspace 文件编辑接口尝试覆盖，再尝试删除和移动同一路径 | 服务端拒绝修改已登记 revision（403）；原内容和片段保持一致 | |
| E3 | 上传一张图片并询问图片内容；再上传超过单轮视觉数量限制的图片 | 实际送给模型的图像数与 UI 状态一致；未送达模型的图片不能显示为已视觉读取 | |
| E4 | 上传音频和视频附件，检查聊天回答、附件状态、历史和预览/播放 | 当前自动化覆盖上传及受保护预览；音视频内容转写/抽帧理解若尚未接入，记录为未支持，不得将路径提示当成已理解内容 | |
| E5 | 在 HTTPS 测试站点允许麦克风，录制短语音并提交；再拒绝麦克风权限 | 配有可用 STT Provider 时能返回识别文本；拒绝权限时给出可恢复错误；无 Provider Key 时记录为“Provider 未测” | |
| E6 | 向 STT 上传超过服务端上限的音频（16 MiB） | 返回 413；请求不会被转发给 Provider | |
| E7 | 在管理员配置页切换 STT/TTS Provider，分别试听和转写 | 配置成功时端到端工作；缺失凭据、browser-only 路径或上游错误有明确提示，不得显示成功 | |
| E8 | 创建 Cron，先用 `run now` 执行，再停用/删除，另以普通用户读取其他用户任务 | 只能读取本人或授权任务；停用/删除阻止未来调度；记录当前 run-now 为异步触发，接口 204 不代表任务成功完成 | |
| E9 | 创建一次性 `date:` Cron，等待触发后重启测试服务，再检查任务列表和调度 | 触发时先持久化停用；重启后不会重新执行已触发的单次任务 | |

**OCT-004 当前已知边界：** 本轮新增自动化保护覆盖已登记聊天文件通过 workspace 写入、删除、移动的绕过路径、STT 文件上传上限、一次性 Cron 触发后的重启重复调度，以及 Admission 会话过期清理。音频附件转写、视频抽帧、持久运行历史与正在运行任务取消仍未交付。真实语音服务需要 Provider 凭据；默认 `browser` Voice Provider 不会自动为演示页完成 STT/TTS，需先配置可用云 Provider 才能跑 E5/E7。
