# 住院登记 · 页面规格与数据基线

> 本文件是 `docs/pages/inpatient-registration/index.html` 的唯一输入。改页面先改这里，
> 再改页面，再由 `PROGRESS.md` 记录一次进度。

## 1. 页面是什么

HIS 住院管理里的业务屏：**住院登记**（住院处窗口）。把门诊已开出的住院申请单转成正式住院记录，
生成住院号并进入待入科队列。不是患者端、不是移动端、不是营销页。

- 主用户：住院处登记护士（40 岁以上占比高），单笔目标 ≤ 20 秒。
- 次用户：护士长 / 医务处抽查留痕（谁在什么时间登记了谁）。
- 环境：护士站 21–24 寸屏，1440×900 为准，1280 宽不出横向滚动条。

## 2. 结构（方向 B · 临床密集工作台）

```
顶栏     HIS / 住院管理 / 住院处 · 3 号窗口 · 班次 · 今日已办理 · 操作人 · 同步时刻
页头     住院登记 + 办理新的住院记录；登记、分床和实际入科分别留痕。 · 待办理 n / 待患者确认 m · 刷新队列
主 tab   门诊住院申请 n  |  登记队列 · 02 n        ← 右端：同步时间 · 60 秒自动同步
├─ 申请 tab
│   左栏  检索 + 科室 + 状态 → 「患者已确认的住院申请」卡片列表（选中态、空态）
│   右栏  新建住院登记 · 01 → ① 申请与科室 ② 患者与联系人 ③ 办理登记 + 核对进度 n/3
│   底条  已核对身份 ☐ · 提示语 · 取消申请选择 · 确认办理住院登记（保存 HIS 住院登记（线下登记））
└─ 队列 tab
    过滤条 检索 + 科室 + 状态 + 登记日期区间 → 查询 / 重置 → 筛选结果 n/m
    7 列表格 住院号 / 患者 / 患者标识 / 科室 / 住院护士工作组·床位 / 状态 / 登记时间
    表尾     共 n 条 · 每页 20 条 · 上一页 / 1 / 下一页
弹窗     取消申请（原因必选 + 补充说明） · 办理确认（8 格摘要，可返回修改联系人 / 个人信息）
```

## 3. 状态机

```
awaiting 待患者确认 ──患者门诊确认──► confirmed 患者已确认
confirmed ──核对身份 + 选科室病区 + 选工作组──► 可提交 ──确认办理──► registered 已办理（生成住院号）
awaiting / confirmed ──取消申请（原因必填，留痕）──► cancelled 已取消
```

不可提交的三类原因必须在底条红字说清：`患者尚未确认办理住院`、`申请单已取消`、`该申请单已办理`。
