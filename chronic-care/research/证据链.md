# 证据链 · 今日课 CareToday

> 这是 PRD 第一章的弹药库。规则：**每一条产品要求都必须能追到一条证据；每一条证据都必须能被反驳**。
> 证据来源限定为 `research/公众号扫描.md` 已记录的内容 + 公开可查的公司/监管事实。凡属推断的，标「推断」；凡转述未核原文的，标「转述，未核实原文」。
> 强度定义：**强** = 有两个以上独立来源互证，或来自监管原文/临床一线；**中** = 单一来源但来自一手从业者；**弱** = 只有一家之言，或属逻辑推断，需用试点数据补。

## 二、五条反常识结论

### 1. 「打卡提醒不是越多越好」——触达疲劳会杀死留存

**直觉**：患者不打卡是因为忘了，多推几次总能推到他。
**为什么错**：慢病患者的手机里，每一天都有 3–5 个公众号在推健康内容（扫描报告显示几百个医院号在重复同一批选题）。在这种噪声里，第 3 条推送不会提高完成率，只会提高**取关率与消息免打扰率**——而微信服务通知一旦被用户关闭，你就永久失去了这个通道。更隐蔽的伤害是：高频提醒把「管理」变成了「催收」，患者对产品的心理定位从「帮手」滑向「债主」。
**正确做法**：**一次提醒 + 一次补漏 + 一次人工**，三步封顶。07:30 推一次服务通知；11:30 若未完成，企微补一次（带具体动作，不是「别忘了」）；连续 3 天未完成，**停止推送，转人工电话**——因为连续 3 天不动的患者，问题不在提醒，在于他已经放弃了，只有人能把他捞回来。
**对应**：E-03、S-10（新增）。

### 2. 「患者不需要更多知识」——他们需要的是决策卸载

**直觉**：依从性差是因为不懂，所以要科普、要课程、要图文。
**为什么错**：扫描报告里，医院宣教号的产能问题被一句话点破——「同一个选题在几百个号里重复」。知识供给早已过剩，患者缺的不是「低盐是多少克」，而是「今天这顿饭我该不该吃咸菜」。知识增加认知负担，行动指令降低认知负担。这也是「知晓规范、难以践行」这八个字的真实含义：**知道和做到之间隔着的不是知识，是一次具体的、有时间点的、有人验收的动作**。
**正确做法**：把每条知识改写成一个动作 + 一个时点 + 一个验收标准。「低盐饮食」→「今天晚饭的汤不喝（7:00 前勾选）」；「规律监测」→「今天 7:30 测一次，测完拍照」。内容团队 KPI 从「产出篇数」改成「被执行的行动数」。
**对应**：E-02、C-01、C-09。

### 3. 「分层不是为了给患者分级，是为了给护士排序」

**直觉**：红黄绿是医学风险分级，分对了就能管好。
**为什么错**：如果分层的结果只是患者列表上多了个颜色标签，护士的工作量一点没变——她还是要从头翻到尾。分层的产品价值不在「标签」，在**「今天先打哪 30 个电话」这个排序结果**。这也是「人均在管 80 → 200」唯一可能的实现路径：不是让护士干得更快，是让她**只干该干的**。
**正确做法**：分层的唯一出口是 S-01 的待办队列顺序 + 每天的「今日 30 人」清单。红黄绿是内部状态，患者端**永远不显示**自己是什么颜色（显示颜色 = 给患者贴标签 = 增加焦虑与拒访）。规则可配置，但「红灯必进队列首条」不可配置。
**对应**：E-05、S-01、AI-3、PRD 4.1。

### 4. 「AI 越像医生，越没人敢用」

**直觉**：AI 能力强 = 能诊断 = 更有价值。
**为什么错**：医信邦与中国数字医学两篇独立文章把「AI 开处方」列为行业突出问题，这意味着**AI 越像医生，越接近监管红线**；同时，越像医生的 AI 越难被医生采纳——医生不会为一台「可能说错话」的机器背书。反过来，一个「只做整理」的 AI（把 5 分钟的报告解读压成 30 秒的确认）医生愿意用，因为它不夺走判断权，只夺走劳动。
**正确做法**：把 AI 的能力边界写进**产品结构**而不是免责声明：系统内没有处方字段、AI 输出永远是「草稿」、危险级别只升不降、每条患者可见内容带确认人。对外文案统一说「AI 帮你把活干了」，不说「AI 帮你看病」。
**对应**：E-10、AI-1、C-06、PRD 第十章。

### 5. 「免费的患者端不是成本，但 C 端订阅是伪需求」

**直觉**：患者端免费 = 烧钱；那就让患者付费订阅，反正他们愿意为健康花钱。
**为什么错**：鲲鹏会与直销号都说「老龄化为产品付费的意愿高」，但那个「付费」买的是**确定性服务**（一次陪诊、一次上门测压、一次报告解读），不是「每月 99 元的管理费」——后者没有交付物，患者第二个月就会问「我付的钱换来了什么」。lulu 那句「慢病管理花的钱，本质上是替未来的住院费打折」恰恰说明：**这个价值只有付住院费的人（保险/医保）才认，患者本人不认**。
**正确做法**：患者端永久免费，定位是**渠道**（获客 + 数据入口 + 复诊转化的落地页）；要向患者收钱，就卖**一次性、有交付物**的服务（报告解读 30 元/份、陪诊 200 元/次、上门测压 50 元/次），不卖订阅。真正稳定的收入仍然来自机构。
**对应**：E-11、PRD 11.3。

## 三、三类用户的真实动机

> 原则：**嘴上说的是自我形象，真正在意的是损失**。文案要绕过前者，界面要直接消解后者。

### 3.1 患者（55–75 岁，高血压/糖尿病为主）

| | 内容 |
|---|---|
| **他嘴上说的** | 「我想把身体管好」「有没有更好的药」「这个病能不能断根」 |
| **他真正在意的** | ①**别麻烦**——任何超过 3 步的操作都会被放弃；②**别被说教**——他已经被子女和医生说过很多次；③**别让我觉得自己是个病人**——确诊身份是一种耻辱，打卡页每强调一次「患者」就增加一次回避；④**别让我白做**——测了没人看，第二次就不测了 |
| **对文案的影响** | 不说「您已逾期 3 天未测量」，说「今天顺手量一下，30 秒」；不说「您的依从性评分 62 分」，说「这周你做到了 4 天」；不说「患者」说「你」；不出现「控制不佳」「恶化」「并发症风险」这类词，改成「比上次高一点，我们再看看」 |
| **对界面的影响** | 单屏 1 个主按钮；字号 ≥17px、关键数值 ≥32px；提交后**立刻**给一句话反馈（含与上次对比），不跳首页；不显示红黄绿标签；不显示「排名」和「积分榜」（老年人对排名的羞耻感强于激励感）；允许「我录错了」一键重录 |

### 3.2 家属（子女，35–50 岁，异地居多）

| | 内容 |
|---|---|
| **他嘴上说的** | 「我爸妈血压高，我很担心」「有什么我能帮上忙的」 |
| **他真正在意的** | ①**我不在场时出事，责任在我**——所以他要的不是数据，是「今天没事」这个结论；②**我打了电话他们也不听**——所以他要的是一个「第三方」替他开口；③**别让我天天盯**——他的注意力预算是一周 2 次，不是每天 |
| **对文案的影响** | 推送「今天已经测了，128/82，正常」比推送「今天还没测」重要 10 倍——前者给安心，后者给压力；异常时不说「你父亲血压 178」，说「今天数值偏高，我们已经打电话过去了，你可以现在给他打个电话」；每周一封「本周小结」代替每日提醒 |
| **对界面的影响** | 家属端默认只看「做没做 + 有没有异常」，**看不到具体数值**，要看需患者逐项授权（对应 PRD 12 章「授权粒度」）；代打卡入口不超过 2 步；提供「一键呼叫健管师」而不是「联系客服」 |

### 3.3 医护（健管师/护士 25–40 岁；医生 35–55 岁）

| | 内容 |
|---|---|
| **他嘴上说的** | 「我想要一个更好用的患者管理工具」「希望能提高随访效率」 |
| **他真正在意的** | ①**别让我多录一遍**——HIS 里已经有的字段再填一次，是最深的恨；②**别让我背锅**——AI 说错了、患者出事了，签字的是他；③**别让我的绩效说不清**——月底考核时拿不出台账；④**别在我忙的时候弹窗**——上午门诊时间任何打断都是负分 |
| **对文案的影响** | 工作台不说「欢迎回来，今天有 47 位患者需要关注」，说「今天先打这 30 个电话，按这个顺序」；AI 建议必须写成「建议：…（依据：连续 3 天未测）」而不是「AI 分析：该患者风险较高」；驳回 AI 时不说「你确定要驳回吗」，直接给 3 个驳回原因选项 |
| **对界面的影响** | 首屏是队列不是仪表盘；单条随访 ≤20 秒（结构化选项 + 语音转写）；AI 草稿与原文左右分栏，一键采纳；批量操作**只对低风险项开放**（红灯必须逐条）；所有写操作留 `operator_id`，月底可一键导出绩效台账 |

**三者的冲突点**（必须在设计时明确取舍）：患者要「别麻烦我」，家属要「让我知道我爸妈没事」，医护要「别让我多干活」。冲突发生在**触达频率**上：家属想每天知道，患者嫌烦，医护没时间每天发。取舍方案——**默认每天只给患者推 1 条，每周只给家属发 1 次小结，异常时同时通知双方并自动生成医护的处置任务**。
