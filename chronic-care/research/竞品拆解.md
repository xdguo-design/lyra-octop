# 竞品拆解 · 今日课 CareToday

> 目的：把「慢病管理」这个赛道里 10 个真实跑过的玩家拆到可抄/不可抄的粒度。
> 口径：财务数字取自公开披露（年报/招股书/媒体转述），凡我未核到原始财报的，标「需核」；产品机制取自公开产品体验与行业访谈，凡属推断的，标「推断」。
> 用法：每篇末尾的「**对本产品的约束**」是给 PRD 的直接输入，不是背景知识。

---

## 1. 智云健康（9955.HK）

**一句话定位**：把医院慢病科的流程搬上云，再用「院内处方 → 院外药房」的链路把处方变成收入。

**目标客户与付费方**：医院付「院内解决方案」的钱（按医院数 + 模块，需核）；但真正的收入大头在「药店解决方案」与医疗用品（器械、耗材、药品）销售分成。2022 年营收约 28.8 亿元、2023 年约 33 亿元，其中院内解决方案约占三成，药店与用品相关超过一半（需核最新年报）。AgeClub 的质疑很直接：「宣称一站式解决方案，但主要变现来源于医疗用品售卖。」

**入口与载体**：医院内网部署的慢病管理系统（智云医汇）+ 医生端 App + 患者端 App + 合作药店网络 + 自营互联网医院。没有硬件自研，靠对接院内血糖/血压设备。

**核心闭环**：
```
医院部署 → 医生在工作站里建慢病档案 → 开处方/开检验
→ 处方流转到合作药店 → 患者到店取药或配送
→ 用药与指标数据回流 → 复诊提醒 → 再次开方
```
价值不在「管理得好」，在「处方不流失」。这是它能说服院长签字的唯一理由。

**AI 具体用在哪一步**：处方审核与合理用药提示（规则库为主，模型为辅）；面向患者的用药提醒文案生成。不做分诊，不做患者侧报告解读的最终交付（那一步仍归医生）。

**可抄的三点**：
1. **不改医生工作站**。以插件/外挂窗体挂在医生已经在用的界面上，医生不切系统、不二次登录——这是它能铺进数千家医院的工程决策。我们做建档时同理：护士在企微侧边栏里完成，不要求她打开第二个浏览器标签。
2. **把「处方是否流出本院」做成院长看得见的报表**。处方留存率、外流金额、外流品种 Top10。任何 To 医院的产品，第一张报表必须回答「我的钱有没有漏出去」。
3. **极窄的最小字段集**（诊断 + 用药 + 最近一次指标），建档 90 秒内完成。字段越多，一线越会填假数据。

**不可抄的点及原因**：靠医疗用品售卖赚钱。我们没有药品/器械供应链，也没有处方权，抄这条等于把自己做成一个小药房，直接撞 PRD 1.4 的「不做药品电商」。

**对本产品的约束**：它证明了「院内系统卖得出去」，也证明了「只卖 SaaS 不赚钱」。所以我们必须在合同里就把「人力替代」折算成 ROI（少雇 1 个随访护士 8–12 万/年 vs 系统 3 万/年），而不是等客户自己算明白。

## 2. 医联 / Medlinker

**一句话定位**：从医生社区切进互联网医院，选一个专科（肝病）做纵深，用「专科服务包 + 药品履约」变现。

**目标客户与付费方**：患者付服务包与药费；药企付学术推广与患者管理项目费（这是它最稳定的 B 端收入）；医生端免费（这是它的资产）。2023 年起对外主推 MedGPT，收入结构未单独披露。

**入口与载体**：医生端 App（起家资产，实名医生社区）+ 患者端 App + 微信服务号 + 自建云药房 + 线下合作药房。没有医院 HIS 依赖，这是它比智云轻的地方。

**核心闭环**：
```
医生在社区里发内容/病例 → 患者循内容进来 → 线上复诊（图文/视频）
→ 开方 → 云药房履约 → 用药随访（医生助理/AI）
→ 复诊提醒 → 复购服务包
```
关键设计：**以「病种」而不是「医院」为单位组织供给**。肝病患者可以在全国找医生，不受地域限制。

**AI 具体用在哪一步**：MedGPT 做预问诊（把主诉结构化成病历草稿）与随访对话；AI 生成的内容必须由医生署名发布。它公开强调「AI 做辅助，不做诊疗决策」，这个表态本身就是合规资产。

**可抄的三点**：
1. **专科纵深的组织方式**：一个病种配一套「指南摘要 + 患者路径 + 话术 + 复诊节奏」，而不是一个通用平台。我们的「病种任务包」模板市场应该按这个粒度切（高血压/糖尿病/慢阻肺各一套，不共用一套话术）。
2. **预问诊结构化**：患者进来先答 5 个问题（症状、用药、最近一次指标、想解决什么），医生接诊时看到的是摘要而不是聊天记录。我们的随访记录可以复用这个「5 问出摘要」的交互。
3. **医生署名的内容资产**：医生发的每篇内容都挂他的实名与科室，患者信任的是人不是平台。我们的 AI-4 内容生产必须保留「本院医生署名」这一层。

**不可抄的点及原因**：处方与药品履约。医联的闭环里，钱是在「开方—发药」这一跳产生的；我们没有这一跳，也就没有这条收入，不能把商业模型建在它上面。

**对本产品的约束**：证明「专科纵深能建立内容壁垒」，也证明「没有处方权的玩家拿不到药那一份钱」——所以我们的收入只能来自机构的效率预算，产品必须把「效率」量化到可验收。

## 3. 微医

**一句话定位**：以互联网医院为牌照底座，跟地方政府共建「数字健共体」，用医保按人头付费的结余做商业模式。

**目标客户与付费方**：地方政府 + 地方医保（按人头总额包干，结余留用）；医院（共建与信息化）；保险与会员（补充）。C 端问诊本身基本不赚钱，是流量入口。

**入口与载体**：微医 App + 各地互联网医院（乌镇互联网医院是起点）+ 基层卫生机构的智能分级诊疗工作站 + 区域健康门户。它是这 10 家里最「重」的一家，落地要进卫健委的盘子。

**核心闭环**：
```
政府签约 → 基层机构接入平台 → 居民家庭医生签约
→ 慢病按人头包干（医保预付）→ 平台提供复诊/用药/检验/转诊
→ 减少不必要住院 → 结余由医保与平台分成
→ 用结余继续扩签约人群
```
这个闭环里，「管理得好」第一次直接等于「赚到钱」——因为花超了是自己的，省下来也是自己的。

**AI 具体用在哪一步**：AI 分诊/导诊（把患者导到正确的科室与层级）、AI 辅助诊断（基层医生侧的提示）、健康画像与风险分层。核心是**给基层医生做能力补位**，不是给患者做客服。

**可抄的三点**：
1. **家庭医生签约服务包的「清单化」**：把「签约」这个虚词拆成 12 项可勾选动作（每年 1 次体检、4 次随访、无限次咨询……）。我们卖机构版时也该这么写：不是「慢病管理服务」，是「建档 1 次 + 随访 12 次 + 报告解读 4 次 + 预警处置不限」。
2. **监管驾驶舱**：卫健委要看的是「辖区签约率、规范管理率、血压控制率、住院率」，不是患者列表。S-08 看板要做「上卷」这一层。
3. **分层签约**：基础包（免费/医保）与增值包（自费）分开，增值包才是利润。

**不可抄的点及原因**：政企共建。一个区域项目从签约到跑通要 18–24 个月，需要地方政府关系与医保谈判能力，跟 8 周 MVP、3.5 人团队不是一个物种。

**对本产品的约束**：证明「支付方一旦变成医保，产品形态会被彻底改写」——按人头付费要求的是**控费证据**（住院率、急诊率），而不是打卡率。我们服务的是没有医保结余分配权的机构，所以只能卖效率，不能卖控费。

## 4. 京东健康（6618.HK）

**一句话定位**：用零售药房的现金流养互联网医院，用 AI 随访把「用药周期」拉长，本质是医药电商的服务化外挂。

**目标客户与付费方**：患者买药（自营商品收入占绝对大头）；药企（营销、患教、患者项目）；保险。2023 年营收约 535 亿元，其中医疗健康服务收入占比不足 5%（需核年报）——这个比例本身就说明了它的商业模式：**服务是获客与留存的成本项，不是收入项**。

**入口与载体**：京东 App 内的「看病买药」频道 + 京东健康 App + 线下京东大药房 + 合作医院。没有硬件，没有院内系统。

**核心闭环**：
```
搜索症状/药品 → 在线问诊（低价引流）→ 开方
→ 京东大药房履约（次日达）→ AI 随访：用药提醒、复诊提醒、不良反应回访
→ DOT（用药疗程天数）延长 → 复购 → 客单价提升
```
它对外披露的核心运营指标不是「打卡率」，是 **DOT**——慢病患者用药疗程环比延长 37%（动脉网报道，厂商口径）。

**AI 具体用在哪一步**：AI 随访（自动消息 + 语音外呼，回收「吃了吗/有不良反应吗/该复诊了」三个字段）；AI 用药助理（药品说明书问答）；大模型做检验报告解读（京医千询）。AI 全部落在**履约之后的留存环节**，不在诊前分诊。

**可抄的三点**：
1. **用「用药周期」而不是「日历周期」驱动触达**。它的随访时点是「按一盒药该吃完的那天」，不是「每周一上午 9 点」。我们 C-04 的剩余药量推算应该成为**主触达时钟**，日历只是兜底。
2. **DOT 作为北极星的下游指标**：我们不把 DOT 当北极星（会诱导多开药），但可以当**用药依从性的代理指标**放进 S-08，验证「管理有没有真的延长治疗」。
3. **随访话术只问三个字段**。京东的 AI 外呼不是聊天，是三个结构化回收项。我们的 AI-6 语音外呼如果做成「自由对话」，成本会翻三倍且无法统计。

**不可抄的点及原因**：零售基因 + 履约网络。它的随访之所以能闭环，是因为「提醒复诊」的下一步是「在它这里下单」；我们提醒复诊的下一步是「去那家诊所」，中间没有交易，不能照搬它的转化设计。

**对本产品的约束**：证明了「AI 随访能把留存做上去」，但也证明了**没有交易环节的随访很难独立收费**——这正是我们必须把「复诊转化」做成可计价单元（C-08 + 到院签到）的原因。

## 5. 平安健康（1833.HK，原平安好医生）

**一句话定位**：把「一个家庭医生 + 一个档案」卖给保险客户与企业，用会员制把医疗服务变成可续费的订阅。

**目标客户与付费方**：平安集团体系内的金融客户（F 端，历史占比约四成）、企业员工健康（B 端）、个人会员（C 端年费，数百元级）。2023 年收入约 46.7 亿元，2024 年首次实现年度盈利（需核最新财报）。付费方本质是**保险**——它买的是「客户健康度提升 → 赔付下降 + 加保率提升」。

**入口与载体**：平安健康 App + 平安金管家（金融客户的主入口）+ 企微 + 线下检测中心 + 合作医院。它是 10 家里「入口最不依赖医院」的一家。

**核心闭环**：
```
保险/银行客户被导流 → 建档 + 分配固定家庭医生
→ 7×24 问诊、体检解读、慢病随访
→ 需要时转诊/安排就医（确定性服务做钩子）
→ 年度会员续费 + 保险加保
```
关键设计：**医生是「固定分配」的，不是「抢单」的**。用户第二次进来还是那个人，这带来关系感，也带来责任归属。

**AI 具体用在哪一步**：AI 辅助医生写病历与推荐检查（医生侧提效）；AI 预问诊；AI 健康管家做日常提醒与报告解读初稿。它对外从不宣传「AI 看病」，只宣传「AI 让医生更快」。

**可抄的三点**：
1. **固定责任人**。一个患者从建档起就绑一个健管师，换人要交接、要通知患者。我们的 `primary_nurse_id` 必须是硬约束，不是「谁有空谁处理」的池子。
2. **服务包分层**：免费（问诊 + 科普）/ 会员（体检解读 + 慢病随访）/ 高端（就医协助 + 二次诊疗）。分层不是功能阉割，是**响应时效**分层（免费 24h 回，会员 2h 回）。
3. **用「确定性服务」做钩子**：挂号协助、报告代取、住院安排——这些患者能立刻感知价值，比「健康管理」这种抽象承诺有效得多。我们可以把「代约复诊 + 到院有人接」做成第一个可感知的价值点。

**不可抄的点及原因**：保险导流。它的获客成本接近零，因为客户是集团送的；我们的每一个机构客户都要地推。

**对本产品的约束**：证明「订阅制在支付方是保险时成立」，也证明「支付方不是保险时，订阅制只能卖给机构，不能卖给患者」。

## 6. 妙健康 / 妙医

**一句话定位**：把健康行为量化成一个可打分、可兑换、可卖给保险公司的「健康分」，用企业福利预算和保险采购做收入。

**目标客户与付费方**：企业 HR 的员工健康福利预算（人均 100–300 元/年，需核）；保险公司（健康管理服务采购、控费分成）；地方政府体检与慢病筛查项目。妙医（旗下互联网医院）承接问诊与处方。

**入口与载体**：妙健康 App + 企微/钉钉 + 自研硬件（妙+ 手环、血压计、体脂秤）+ 体检机构 + 保险公司 App 内嵌。

**核心闭环**：
```
企业/保险采购 → 员工测评（问卷 + 体检数据 → M 值健康行为指数）
→ 生成个性化任务（走路、测压、早睡、戒烟）
→ 完成任务得积分 → 积分兑实物/保险折扣
→ 群体健康报告回流给 HR/保险公司 → 续约
```
它的产品核心不是「管理疾病」，是**「让健康行为可被计量、可被激励」**。M 值是它最值钱的资产，因为它把「你健康吗」变成了一个可对比的数字。

**AI 具体用在哪一步**：健康风险评分与分层（规则 + 模型）；个性化任务推荐（「你这周该重点改睡眠」）；AI 健康助手做问答。AI 在这里的角色是**分配任务的调度器**，不是医生。

**可抄的三点**：
1. **行为积分兑实物**。这是留存最便宜的手段：一盒鸡蛋的成本远低于一次电话随访，但即时反馈感强得多。我们可以做「连续 7 天打卡兑一次免费复诊挂号费/一次上门测压」——把积分兑成**机构自己的服务**，成本是边际成本不是现金。
2. **把健康行为拆成 8 个可加分的维度**（运动、饮食、睡眠、用药、监测、情绪、烟酒、就诊），每个维度有明确阈值。这样「健康分」才不是玄学，患者也知道「我怎么才能加分」。
3. **给 HR/主任的「群体健康风险报告」**：不是患者列表，是「你这个群体里 32% 的人血压未达标、18% 的人半年没测过血糖」。买单的人要的是这个。

**不可抄的点及原因**：硬件。妙健康自研手环与体脂秤，硬件是它数据采集的入口，也是它的库存与售后负担。我们明确不做硬件，只做蓝牙协议接入，抄这条会把团队拖进供应链。

**对本产品的约束**：证明「行为激励能提升留存」，也证明「激励必须有预算来源」——企业福利预算在国内中小企业几乎不存在，所以我们的积分只能兑机构自有服务，不能兑现金或实物商品。

## 7. 圆心科技 / 妙手医生

**一句话定位**：用 DTP 药房承接院外处方，用互联网医院做复诊开方，用保险（惠民保/特药险）做支付，三家马车围着「处方外流」转。

**目标客户与付费方**：药企（特药渠道服务、市场服务，这是它最大的收入来源）、保险公司（惠民保与特药险的运营与理赔服务）、患者（药费）。2022 年营收约 77.8 亿元、2023 年约 100 亿元量级（招股书口径，需核最新）。

**入口与载体**：圆心大药房（DTP，300 家量级）+ 妙手医生 App + 圆心惠保（保险经纪/技术服务）+ 医院旁边的院边店。**它的入口是「医院门口那家药房」**，不是线上。

**核心闭环**：
```
医院就诊开方 → 处方外流到院边 DTP 药房
→ 药师建档、用药指导、不良反应随访（真人，1 对多）
→ 保险支付（特药险/惠民保）→ 定期复购与配送
→ 药企拿到「患者用药依从性」数据 → 付市场服务费
```
注意：它的「随访」是**药师做的**，不是护士，也不是 AI。这是它最容易被低估的能力。

**AI 具体用在哪一步**：处方审核（配伍禁忌、剂量）；药师助手（查说明书、查相互作用）；患者用药随访的自动外呼与召回。AI 的定位是**给药师扩容**——一个药师从管 200 人变成管 600 人。

**可抄的三点**：
1. **「谁有专业身份，谁做随访」**。药师随访的可信度高于客服，因为患者知道「他懂药」。我们的随访必须挂护士/医生实名，不能是「健康管家小助手」。
2. **依从性数据产品化**：圆心把「这个患者 12 个月吃了 9 个月的药」卖给药企做市场服务。我们同样可以把「在管人群的用药依从性分布」做成机构/药企可采购的报告——这是 PRD 里没有但值得加的一条收入线（不碰药，只卖聚合数据）。
3. **特药患者的「1 对 1 全程陪跑」**：从首方到停药，一个固定的人跟到底，包含配送、报销、不良反应三件事。我们的红灯患者应该享受同等待遇。

**不可抄的点及原因**：DTP 药房是重资产（选址、库存、冷链、医保资质），且它的收入命脉是「处方外流」这个政策红利，政策一变就伤筋动骨。

**对本产品的约束**：证明「院外那一段确实有钱」，但钱在**药**和**保险**上，不在**管理**上。我们要拿的是机构为「少雇人」付的钱，不能幻想从药企拿到大预算。

## 8. 微脉

**一句话定位**：白标进公立医院的公众号，用「孕产」这种高频专科做患者付费服务包，再复制到慢病。

**目标客户与付费方**：医院（共建与技术服务费）；患者（服务包，孕产类数百到数千元，慢病类数百元/年）；地方政府（部分区域项目）。它是 10 家里**最像我们**的一家——同样做「离院之后的陪伴」，同样靠真人管家。

**入口与载体**：医院微信公众号/小程序（白标，患者看到的仍是医院品牌）+ 微脉 App（弱化）+ 院内自助机 + 企微。**患者不需要装新 App**，这是它扩张快的原因。

**核心闭环**：
```
医院签约 → 科室上线（产科/妇科/慢病科）
→ 医生在诊间推荐服务包（一句话 + 二维码）
→ 患者购买 → 分配专属健康管家（真人，1 对 200 左右）
→ 7×12 在线答疑、产检提醒、报告解读、异常升级到医生
→ 产后/年度续费或转介绍
```
它的核心资产是**管家团队的服务 SOP**，不是软件。软件只是让一个管家能管 200 人。

**AI 具体用在哪一步**：AI 客服（首响秒回，兜住 70% 的重复问题）；AI 随访外呼（产后 42 天回访、慢病月度回访）；AI 报告解读（有限，仍以医生/管家口径为准）。AI 用来**压低管家的单人成本**，不用于替代管家。

**可抄的三点**：
1. **白标进医院公众号**。这是渠道策略里性价比最高的一招：患者不用装 App、不用记新品牌，医院也愿意（流量留在自己号里）。我们应该把「小程序可挂载到机构公众号菜单/被医院服务号推送」做成标准交付项，而不是让患者扫我们的码。
2. **1 对 200 的服务比**。不是 1 对 1（太贵），也不是纯自助（没温度）。这个比值决定了定价：200 人 × 300 元/年 = 6 万/管家/年，扣掉人力还有毛利。
3. **服务包写成可计价单元**：「12 次随访 + 4 次报告解读 + 无限次咨询 + 2 次陪诊」。患者能算清自己买了什么，机构也能算清成本。

**不可抄的点及原因**：依赖医院品牌与医生背书。微脉的服务包能在诊间卖出去，是因为医生开口了；我们没有诊间话语权时，只能靠机构老板自上而下推。

**对本产品的约束**：证明「微信生态 + 真人管家 + 服务包」这条路在国内走得通，且不需要硬件、不需要处方权。这是对我们模式最强的正面证据。

## 9. Livongo（美国，2020 年被 Teladoc 以 185 亿美元收购）

**一句话定位**：把糖尿病监测做成「测完 30 秒内一定有人回应」的订阅服务，卖给美国自保雇主，硬件免费送。

**目标客户与付费方**：自保雇主与大健康计划（按 PMPM 付费，公开口径约每人每月 60–75 美元，需核）；患者付 0 元。逻辑是：雇主算的是「一个糖尿病员工的并发症住院费用 vs 每月 70 美元」，只要降得住就续约。

**入口与载体**：免费寄到家的联网血糖仪 + 无限量试纸（这是关键：**试纸不要钱，患者就没有「省着测」的理由**）+ App + 真人教练（CDE，注册糖尿病教育师）。

**核心闭环**：
```
雇主采购 → 员工注册（或理赔数据筛出糖尿病人）
→ 一周内收到设备 → 每天测血糖
→ 数据实时上传 → 规则引擎 + AI 在 30 秒内给下一步
   （「210，走 15 分钟，20 分钟后复测」）
→ 连续异常自动转 CDE 电话 → 行为积分（每次测量给积分，可换礼品卡）
→ 12 个月后雇主看到医疗费用下降 → 续约
```
它真正的产品不是血糖仪，是**「测了就有反馈」这个承诺**。没有反馈，设备就是废物。

**AI 具体用在哪一步**：实时规则引擎 + 个性化提示（「你昨晚吃面后血糖高，今天晚餐换一下」）——注意这是**行为建议**，不是医疗建议；高危转真人。AI 的位置在「测量之后的那 30 秒」，这是全流程里用户注意力最高的时刻。

**可抄的三点**：
1. **测完必须有反馈，且要快**。这是留存的唯一原因。我们的打卡页在提交后必须立刻给一句话（「今天 128/82，比上周稳」），而不是跳回首页。PRD 场景 B 的「立刻看到连续 12 天」方向对，但反馈内容太薄，应该加「与上次对比」。
2. **积分即时到账**。Livongo 的积分是秒到的，不是月底结算。即时反馈是行为强化的核心，延迟反馈等于没有反馈。
3. **高危自动转真人，AI 不越界**。它的 AI 从不说「你该加药」，只说「现在做什么动作」。这与我们 AI-1/AI-5 的护栏设计完全一致，可以直接引用为行业先例。

**不可抄的点及原因**：硬件免费 + 保险付费。美国的雇主有明确的财务动机（自保，员工医疗费用自己扛），中国没有这一层；我们送不起设备，也没有人为设备付月费。

**对本产品的约束**：证明「反馈速度」比「内容质量」更决定留存；也证明**这套模型离开保险支付方就不成立**——所以我们不能抄它的收入结构，只能抄它的交互。

## 10. Omada Health（美国，DPP 糖尿病预防，2025 年上市）

**一句话定位**：把 CDC 的「糖尿病预防计划（DPP）」做成 16 周标准化课程 + 长期维持的数字化产品，按结果向雇主/保险收费。

**目标客户与付费方**：雇主与商业保险（按参与人数或按结果付费——完成课程或减重 5% 才收全款，需核）。2024 年营收约 1.7 亿美元量级。

**入口与载体**：App + 联网体重秤（免费寄）+ 真人教练 + 同伴小组（8–12 人一组）。没有医院，也没有医生。

**核心闭环**：
```
雇主/保险采购 → 风险问卷 + 化验筛出糖尿病前期人群
→ 寄秤 → 16 周核心课程（每周 1 课 + 每周称重 + 小组讨论）
→ 每周教练点评（1 对多）→ 毕业后进入长期维持模式
→ 12 个月评估（体重、A1c、步数）→ 达标则客户付全款
```
它最聪明的地方：**有明确的开始和结束**。16 周是可承诺的疗程，不是「终身管理」这种无法交付的承诺。

**AI 具体用在哪一步**：课程内容的个性化改写（按饮食偏好生成不同版本）；教练侧的「谁掉队了」预警（谁两周没称重、谁课程没看）；消息推送的时机优化。AI 不面对患者做医疗判断，只做**教练的放大器**。

**可抄的三点**：
1. **16 周结构化课表**，不是一个无限滚动的任务流。有终点，患者才知道自己在哪一段；有终点，机构才敢承诺结果。我们的 C-09 健康课表应该改成「首 4 周强化 + 12 周巩固」的两段式，而不是「7 天/30 天课程卡」。
2. **同伴小组（8–12 人）**。一个教练带 8 个小组，比 1 对 1 便宜 8 倍。社群不是用来发通知的，是用来让患者互相看见的。我们的私域社群应该按「病种 + 分层 + 入组周」编组，而不是一个大群。
3. **按结果付费的合同结构**：它敢这么签，是因为结果指标（减重 5%）客观、可归因、周期明确。我们可以对机构做**软性对赌**：首年达不到 60% 活跃管理率，第二年打 7 折。

**不可抄的点及原因**：按结果付费需要 12 个月归因窗口 + 客户愿意接受「可能不付钱」。国内基层机构的预算年度是自然年，且采购流程不接受「效果不确定则不付款」，抄这条会死在合同评审。

**对本产品的约束**：证明「有终点的课程 + 小组 + 教练」是低成本高留存的组合；也证明**结果付费的前提是结果可被客观测量**——我们的北极星（30 天活跃管理率）是过程指标，不能直接用于对赌，必须补一个客观结果指标（如血压达标率）作为附加条款。

## 跨竞品的五个规律

**规律一：支付方决定产品形态，产品形态决定一切细节。**
支付方是保险（Livongo、Omada、平安健康），产品就长成「预防 + 控费 + 结果付费」，指标是住院率与赔付率；支付方是医保（微医），产品就长成「按人头包干 + 结余留用」，指标是住院率与外转率；支付方是患者的药费（智云、京东、圆心、医联），产品就长成「处方不流失 + DOT 延长」，指标是复购；支付方是机构的人力预算（微脉、妙健康），产品才长成「一个人管 200 人」，指标是人均在管数。
（来自：Livongo、Omada、平安健康 / 微医 / 智云、京东健康、圆心、医联 / 微脉、妙健康）
→ 推论：我们既然卖给机构，北极星就必须是**效率型指标**（活跃管理率、人均在管数），不能是**结果型指标**（血糖达标率）——结果指标的归因周期超过合同周期，客户不会为它签字。

**规律二：硬件是入口，不是壁垒。**
Livongo 免费送血糖仪，妙健康送手环，智云对接院内设备但自己不做硬件，Omada 送体重秤。没有一家把硬件当护城河——硬件只是**让数据自动流进来**的管道，一旦数据能通过 OCR、蓝牙协议、患者手输拿到，硬件就退化成成本项。
（来自：Livongo、Omada、妙健康、智云健康）
→ 推论：PRD 1.4「不做硬件」是对的，但「只做接入协议」不够——必须把**拍照识别血压计屏幕**（C-02）当成一等公民做，因为那是零成本的数据入口，覆盖 80% 没有蓝牙设备的老年患者。

**规律三：AI 只出现在人力最贵的那一步，且永远不越过「建议」这条线。**
Livongo 的 AI 在「测完 30 秒」那一步（因为真人教练接不住每天百万次测量）；京东的 AI 在 DTA 随访外呼（因为电话人力最贵）；圆心的 AI 在药师审核与召回；微医的 AI 在基层分诊（因为基层医生最缺）；Omada 的 AI 在教练的「谁掉队」预警。没有一家的 AI 在做诊断。
（来自：Livongo、京东健康、圆心科技、微医、Omada Health）
→ 推论：我们的 AI 排序应该是「报告解读（省医生 5 分钟）> 随访话术（省护士 3 分钟）> 待办排序（省护士 30 分钟/天）> 内容生产 > 患者问答 > 语音外呼」。PRD 6.1 的顺序与此一致，可以放心执行；但**AI-3 待办排序**被低估了——它才是人均在管数从 80 到 200 的那一步。

**规律四：「药」这一环既是收入引擎，也是合规天花板。**
四家（智云、京东、圆心、医联）的钱都在药上：处方流转分成、药品零售毛利、DTP 渠道服务费、云药房履约。但正因为钱在药上，它们全部被《细则》钉死在「复诊续方」这个窄门里，且都背着「先药后方」的质疑。反过来，不碰药的两家（微脉、妙健康）收入规模小一个量级，但合规风险也小一个量级。
（来自：智云健康、京东健康、圆心科技、医联 / 微脉、妙健康）
→ 推论：PRD 1.4「不做药品电商」让我们放弃了最大的一块收入，这是对的，但必须补一条替代收入线，否则单靠 9,800–29,800 元的 SaaS 年费养不活 3.5 人团队。最小可行的补充是**复诊转化分成**（按到院人次收 5–15 元服务费）和**聚合数据报告**（卖给机构做区域对标，不卖给药企个体）。

**规律五：留存靠「人」，内容只是触达素材。**
Livongo 靠 CDE 教练，Omada 靠每周教练点评，微脉靠 1 对 200 的健康管家，圆心靠药师，平安靠固定分配的家庭医生。没有一家靠「更好的科普内容」留住患者——内容的作用只是给那个「人」一个开口的理由。
（来自：Livongo、Omada Health、微脉、圆心科技、平安健康）
→ 推论：PRD 场景 B 里「首周护士 2 次电话」应该从「最佳实践」升级为**系统强制**：建档后 72 小时内必须有 1 次人工触达，未完成则进入护士的待办队列首条。AI 内容生产（AI-4）的定位要下调——它是让护士有话可说的素材库，不是留存手段。
