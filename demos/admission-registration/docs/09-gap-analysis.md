## 2. P0 · 联系电话数字键盘点了不出现（真机必现）

**现象**：表单页点击「联系电话」显示框，无任何反应，键盘不弹出。键盘是第 1 页唯一必填的可编辑字段的入口，卡死即整条流程走不完。

**证据**：Playwright 真点击后对面板做 MutationObserver，样式序列为 `""`（打开）→ `display: none`（立刻关闭）——同一次点击里被开了又关。

**根因**：`frontend/src/components/KeypadDialog.vue:39`

```js
onOutsideClick(event) {
  if (!this.$el.contains(event.target)) this.close()   // $el 只有面板本身，不含触发按钮
}
```

`this.$el` 是 `.keypad-panel`，触发按钮 `.keypad-trigger` 在它外面。而监听器是在 `AdmissionForm.vue:86` 的 `@click` 置 `true` 后、由 `watch` 里的 `$nextTick` 注册的——微任务在按钮点击回调返回、事件继续冒泡到 `document` 之前执行，于是**这次点击本身**立刻被判定为"外部点击"。

**为什么 38 个前端测试全绿**：`frontend/tests/full-workflow.test.js:215` 用 `wrapper.find('.keypad-trigger').trigger('click')`——jsdom 里整个派发过程在同一个 JS 栈内完成，监听器之间的微任务检查点不存在，双触发不会发生。这类"组件外点击关闭"必须真浏览器才能测出来。

**修法（任一）**：

1. 让面板与按钮共用一个容器，在容器上判断 `contains`；
2. 改成 `pointerdown` + `setTimeout(…, 0)` 注册监听；
3. 传 trigger 的 DOM 引用进 `KeypadDialog`，两者任一命中即视为内部。

顺带：`App.vue:90` 与 `App.vue:52` 的 `@keypad="keypadVisible = true"` 是死通道——`AdmissionForm` 从不 emit `keypad`，页面里实际存在**两个** KeypadDialog 实例（一个永远 `display:none`）。建议只留一处。

1. `03-prototype.md:9` 写"翻页箭头和页码在表单卡下方"——原型没有页码。
2. `05-acceptance.md:11` 把"数字键盘可完成 11 位号码"列为验收项、`06-verification.md` 声称流程测试通过——真机不可用，属于假绿。

4. `06-verification.md` 结尾"仅手工检查了身份核验页，未做完整真实浏览器旅程"——本轮补上后立刻出 P0，说明"页面级"缺口就是被这句话掩盖的。

## 6. 建议修复顺序

1. **P0 键盘**：改 `onOutsideClick` 归属判断 + 补一条 Playwright 真点击回归用例（jsdom 测不出）。
2. **让演示能跑通**：mock phone 预填、地区库补到原型示例的广东省/佛山市/禅城区（或把语音示例改到已有省份）。
3. **降级语音提示**：401 时静默或只在首页提示一次，别每页盖住品牌区。
4. **对齐细节**：国籍/民族补星、分页改双箭头去页码、mock 证件/姓名换成合规假数据、首页补用户条。
5. **确认身份页读卡器默认展示尺寸**：保留缩略图点击放大，或直接展示原型大图与卡槽标注；页面结构已按原型对齐。
