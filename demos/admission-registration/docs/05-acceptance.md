## 4. 对抗性验证与后续接口测试

| 攻击/失败             | 具体测试                                    | 防护/结果要求                                                      |
| --------------------- | ------------------------------------------- | ------------------------------------------------------------------ |
| 身份未确认绕过登记    | 直接调用提交接口且无 identityToken           | 返回401，不创建登记结果                                            |
| 模型改证件/塞未知枚举 | 候选含id_number/marriage、relationship=朋友 | 忽略只读/未知键，枚举不合法不写                                    |
| 号码幻觉/证件子串     | 原文缺候选手机号或长数字中含手机号          | 不回填，用户人工确认                                               |
| 新患者被旧回调污染    | reset后旧generation回调                     | 不改新转写/草稿                                                    |
| 数据量攻击            | 单位51字、地址201字、AI入参2001字           | 前后端共用合同/服务端复验拒绝超限                                 |
| HTML/脚本注入         | 单位`<script>`、地址/转写含HTML             | 单位校验拒绝；自由文字仅文本渲染，无脚本执行                       |
| 重复提交/结果未知     | 双击、同键重试、服务断线                    | 客户端锁一次；adapter同幂等回执，未知先查询                        |
| 媒体资源耗尽          | 录音中切页/取消/卸载、连续20次失败          | 尚未运行资源耗尽测试；验收tracks/AudioContext/URL/WS均释放       |
| 登录失效/越权         | 平台401/403                                 | 下一阶段清理身份与草稿、不静默换供应商                             |
