# 入院登记智能语音对话跨页保持设计

## 2026-10-20 用户纠正后的现行规则与调试记录

以下现行规则覆盖本文后面的初版方案。用户明确要求：首页打开对话后，无论语音还是文字，后续办理页面都保留同一段对话，切页追加当前页面名称与下一步操作。直到主动收起、完成返回首页、退出或超时清理；结果页仍保留对话。

- 假设 1：`begin()` 依据语音来源标记关闭文字对话。最小用例“首页文字打开→发送入院需求→身份核验”实际得到 `conversationVisible=false`，确认根因。
- 假设 2：按页面切换消息数组导致前文消失。贯穿身份核验、申请单、两页表单、核对、结果的渲染前缀断言用于复现与回归。
- 修复：保留分阶段业务会话数组，显示层统一使用只追加的 `dialogMessages`；所有实时消息与表单提问写入这条记录。以页面及表单步数识别切换，追加页面操作引导。历史恢复同一 session 不重复追加。
- 身份页按钮、申请单确认按钮和最终提交继续复用已有服务端流程；不新增模型决策或业务跳转权限。
- 防护：主动关闭后切页不自动重开；迟到响应仍受 generation/token 校验约束；重置/退出/超时清空连续记录；成功结果页保留的是当前办理的脱敏显示记录，完成后清除。
- 自动验证：在 `frontend/` 运行 `npm test`、`npm run typecheck`、`npm run build:dashboard`。关键用例覆盖文字/语音入口、跨页消息顺序、页面提示、结果保留、主动关闭与流程清理。
- 本地浏览器实测：首页文字输入“我要办理入院登记”→身份核验→模拟刷卡→申请单对话确认→基本信息页，连续消息与提示可见。截图 `e2e/artifacts/dialogue-continuity-20261020.png`。

## 初版方案（历史记录，已被以上规则替换）

## 问题拆解

- **目标**：用户从首页麦克风开启智能语音办理后，跨页面时对话框仍可见；身份核验页由 AI 提示放置证件，并可在对话框内触发“模拟刷卡”。
- **约束**：只改变首页麦克风启动的办理流程。手动文字入口继续在切入办理页时收起。沿用 Vue 2、现有 `ConversationDialog` 和 `verifyIdentity()`；不改变身份校验及申请单查询 API，不绕过页面上的核验逻辑。
- **假设**：持久在线仅限当前办理流程，从身份核验页持续至成功结果页；用户主动关闭后不自动重开。结果页/流程重置清除保持状态。
- **失败模式与防护**：
  1. 语音和文字入口被混淆，导致手动输入也持续弹窗：仅在首页语音模式识别出开始办理意图时设置跨页保持状态。
  2. 对话框按钮绕过身份核验，或重复触发核验：按钮只调用现有 `verifyIdentity()`，核验中禁用。
  3. 页面切换后遮罩或对话内容错配：对话框始终由 App 单例承载，随当前页面传入正确提示和消息；失败仍停留当前页并显示既有错误。

## 方案对比与选择

1. **推荐：仅语音入口跨页保持**。符合用户确认的“智能语音”范围，改动和行为影响最小。
2. 文字及语音入口都跨页保持。交互更统一，但超出本次确认范围，也会改变手动文字流程。

选择方案 1。身份核验页的“模拟刷卡”按钮复用页面已有的身份核验处理，不新增模拟成功路径。

## 交互与数据流

1. 首页麦克风入口打开对话框时记录本次对话来自智能语音入口；开始办理意图被接受后，仅该入口设置本次流程的跨页保持状态并切到身份核验页。之后即便用户在弹窗中切换为文字输入，也不改变本次办理来源。
2. 对话框继续显示提示 `请将证件放置到读卡区，然后点击“模拟刷卡”。` 和“模拟刷卡”操作；页面进入身份核验时，现有 TTS 播报这句提示。
3. 点击操作进入原有 `verifyIdentity()`：核验期间按钮禁用；成功后按现有逻辑进入申请单页；失败时保留在身份核验页并显示现有错误。
4. 后续切换申请单、表单、核对页时，语音入口启动的对话框继续可见，底层页面的原有操作不变。用户可主动收起；结果页和重置流程清除此状态。
5. 首页手动文字入口不设置跨页保持状态，继续沿用现有收起行为。

## 对抗性验证设计

- **边界**：首页手动输入启动办理后检查对话框收起；首页麦克风启动后检查身份页对话框和刷卡操作出现。
- **异常**：模拟核验失败后确认仍在身份页，错误可见且可重试；核验中连续点击不能产生并发核验。
- **状态竞争**：核验请求未完成时关闭对话框或重置流程，旧请求不得把页面带入申请单页（复用现有 generation/request 保护并增加回归覆盖）。
- **门禁**：点击对话框按钮必须进入现有身份验证 API；不得直接设置 identity token 或跳转页面。
- **资源/安全**：不新增持久数据、接口、第三方调用或患者身份信息展示；模态遮罩沿用现有滚动锁定和关闭方式。

## 验收标准

- 语音入口的办理对话框在身份核验、申请单、表单和核对页面切换时保持可见，直到用户收起或进入结果页。
- 身份核验页对话框显示指定提示和“模拟刷卡”按钮，点击复用现有核验流程。
- 手动文字入口的跨页表现不变。
- 对话框关闭、核验失败、重复点击、重置及异步请求过期均不导致跳过核验或错误推进。
